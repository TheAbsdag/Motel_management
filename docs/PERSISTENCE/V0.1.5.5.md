# Persistence Schema — V0.1.5.5

**Date**: November 2026 (code state `71d192c`, release `v0.1.5.5`)
**Purpose**: Document the inventory traceability keys.
**Releases**: V0.1.5.5

## Overview

| File | Change | Compatibility |
|------|--------|---------------|
| `data/inventory` | optional `minimum` per item; `"version": 3` | absent in v2 → `0` (only out-of-stock warnings) |
| `data/turn` and `history/turn-<timestamp>` | `inventoryMovements`, `openingInventory`, `closingInventory`; `"version": 4` | absent in v3 → empty lists; the built-in report layout prints no inventory section, while a saved custom template that includes the fields prints its headings with empty values |
| every other file | untouched | read and written as in V0.1.5.4 |

## 1. `data/inventory` — version 3

```json
{
  "inventoryItems": [
    { "itemID": 0, "price": 16000, "itemName": "Nectar 1/4", "quantity": 4, "minimum": 2 }
  ],
  "version": 3
}
```

- `minimum` is the quantity at or below which the product is reported as low.
- `0` means no minimum configured: only `quantity <= 0` is reported as out.

## 2. `data/turn` — version 4

```json
{
  "turnNumber": 3,
  "version": 4,
  "inventoryMovements": [
    { "changeDate": "2026-11-17T20:30:00-05:00[America/Bogota]", "itemID": 0, "itemName": "Nectar 1/4",
      "movementType": "increase", "quantity": 6, "concept": "COMPRA", "cost": 30000 }
  ],
  "openingInventory": [ { "itemID": 0, "itemName": "Nectar 1/4", "quantity": 4, "minimum": 2 } ],
  "closingInventory": [ { "itemID": 0, "itemName": "Nectar 1/4", "quantity": 10, "minimum": 2 } ],
  "turnActivity": []
}
```

- `inventoryMovements` only holds manual movements (increase/consumption with concept
  and, for an increase, total cost). Sales, courtesy sales and refunds stay in
  `turnActivity` and the report reads them from there.
- `openingInventory`/`closingInventory` are the stock snapshots taken when the turn
  starts and when it is printed/closed.
- No quantity is migrated or rewritten. Existing negative quantities are preserved and
  reported as out until the first real count is recorded as a movement.

## 3. Unchanged

`data/roomsInformation`, `data/applicationProperties`, `data/emailConfig`, the print
templates and the backup/history directory layout are unchanged.
